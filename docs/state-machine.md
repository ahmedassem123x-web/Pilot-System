# آلة حالات العقد — 12 حالة

الحالات بالترتيب:
1. draft — مسودة
2. issued — صادر بانتظار القبول
3. accepted — مقبول من الطرفين
4. payment_pending — بانتظار تأكيد المؤسسة المالية
5. payment_confirmed — مؤكد مالياً بمرجع مؤسسة (لا يتحقق بدون مرجع)
6. preparing — قيد التجهيز
7. delivered — مسلّم بانتظار تأكيد الاستلام
8. completed — مكتمل ومغلق
9. disputed — نزاع مفتوح
10. refund_pending — استرداد بانتظار تنفيذ يدوي خارج النظام
11. refunded — مسترد
12. cancelled — ملغى

قواعد الانتقال:
- لا انتقال إلى payment_confirmed بدون financial_reference من المؤسسة.
- لا انتقال مالي آلي أبداً: الإفراج والاسترداد وحسم النزاع يدوي فقط.
- كل انتقال يفتح مهمة تشغيل عند الحاجة، ويسجّل في سجل التدقيق الإلحاقي.
- النزاع يوقف أي خطوة مالية حتى يحسمه موظف بشري.
- الإلغاء لا يحذف العقد، بل يغلقه مع سجل كامل.
