## Defects logged
### UAT-D1 (from E2) — handover-acceptance recording endpoint returns 201 while a product-absent exception is unresolved
- **Script expectation:** attempt buyer acceptance while the exception is unresolved → Rejected.
- **Observed:** `POST /api/transactions/:id/handover-acceptance` returned HTTP 201 for the acceptance message. The guarded transition to `RECEIPT_CONFIRMED` was correctly rejected (HTTP 422, `GUARD_FAILED`) and the state stayed `DELIVERED`, so no acceptance took effect.
- **Severity:** Low–moderate (clarification/UX). No state or financial harm: acceptance cannot take effect while the exception is unresolved. Risk: staff seeing a 201 may believe the acceptance was recorded as effective.
- **Decision needed from Ahmed:** (a) clarify the script (the recording endpoint records a buyer's message; only the guarded transition accepts), or (b) change the endpoint to reject acceptance messages while an operational exception is unresolved. Do NOT treat this as fixed until Ahmed decides.
- **Status:** OPEN.
